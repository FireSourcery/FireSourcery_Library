# Modules

Design notes for one module, at the module's source path: notes on `Peripheral/ADC` go in
`Modules/Peripheral/ADC/`. Notes that cover a whole stack go at the stack's folder:
`Motor/Docs` becomes `Modules/Motor/`.

Rules and patterns that apply across modules go in [../Conventions/](../Conventions/) and
[../Patterns/](../Patterns/README.md), not here. A module's `README.md` stays in the module's
folder.
